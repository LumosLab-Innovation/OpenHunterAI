# Triage labels

These labels exist in the repository. Recheck with `gh label list` before applying;
do not create or rename labels just to match another tool's vocabulary.

| Label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer evaluation required |
| `needs-info` | Waiting on the reporter |
| `ready-for-agent` | Sufficiently specified for an authorized coding-agent task |
| `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | Will not be actioned |

A label does not authorize background work, external writes, or scans.
Follow the [issue workflow](issue-tracker.md) and [contribution policy](../../CONTRIBUTING.md).
